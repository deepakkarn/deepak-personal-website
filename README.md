## Deploy to Cloudflare Pages
1. Extract the ZIP.
2. Log in to Cloudflare Dashboard.
3. Go to **Workers & Pages**.
4. Click **Create application** or **Create project**.
5. Choose **Upload assets** / **Direct Upload**.
6. Upload the contents of this folder or the ZIP contents.
7. Make sure `index.html` is in the root.
8. Deploy.

## Connect Namecheap domain
After deployment:
1. Open your Cloudflare Pages project.
2. Go to **Custom domains**.
3. Add `deepakkarn.com` or `www.deepakkarn.com`.
4. If required, update nameservers or DNS records from Namecheap.
